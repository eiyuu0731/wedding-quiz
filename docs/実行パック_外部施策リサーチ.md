## 1. S2 検品レターDM発送代行（優先順位2位）

- **実勢価格**: 封書DM 1通あたり100〜160円（印刷＋封入＋郵送込み）。小ロット100通なら1.8万円台〜（DM発送センター系）。NEXLINK等の大手は小ロットだと割高（100通7万円）なので避ける。
- **候補**: ①ラクスル（ネット完結・データ入稿が楽） ②DM発送センター系の小ロット特化業者 ③地元の印刷会社（相見積もり用）
- **手順**: ①Claude Codeでレター本文・宛先リスト（CSV）を生成 → ②ラクスルにアカウント作成、封書DMでPDF＋CSVを入稿 → ③校正確認 → 発送。初回は50〜100通でテストし、反応率を見て週次運転に載せる。
- **予算目安**: 週50通×月4回×140円 ≒ 月2.8万円。年40万円の想定通り。
- **今できる準備**: ラクスルのアカウント作成と入稿テンプレの確認（10分）。

## 2. A5 PR TIMES（優先順位4位）— ★無料枠が使える

- **重要発見**: **「スタートアップチャレンジ」= 設立24ヶ月以内の法人は月1件・累計10件までプレスリリース配信が無料**（通常1件3万円）。条件は①企業情報に設立年月を登録 ②配信時にフォロワー3名以上 ③親会社・代理店運用でないこと。
- **手順**: ①10月の法人設立後すぐPR TIMESに企業登録 → ②スタートアップチャレンジに申込 → ③フォロワー3名を確保（知人でよい） → ④第1弾「現役医師がクリニック向けAI導入会社を設立」を配信。
- **配信ネタ計画（無料10本の使い方）**: 設立／診断サービス開始／導入事例1号／補助金採択／セミナー開催／年間削減額まとめ…と、四半期1〜2本ペースで2年使い切る。
- **予算**: 0円（想定していた3万円すら不要）。転載された媒体名はLPの「掲載実績」に即反映。

## 3. S7 商標登録（優先順位5位）

- **候補と実勢価格（1区分・登録料込み総額)**: Toreru 約5.0万円／Cotobox 約5.2万円。2区分ならToreruで約8.7万円。どちらもオンライン完結、Cotoboxは無料で先行商標調査可能。
- **取るべき区分（目安）**: 第35類（広告・SNS運用代行）＋第42類（AI・ソフトウェア提供）。研修事業を本格化するなら第41類（教育・セミナー）を追加。まず35類＋42類の2区分＝約9万円。
- **手順**: ①Cotoboxの無料検索でサービス名の先行商標を確認（5分・アカウント不要） → ②かぶっていなければToreruで出願（最短即日） → ③審査6〜10ヶ月待ち（出願日で先願権は確保される）。
- **今できる準備**: 商品名候補（サービス名・「検品」系の呼称）を確定させること。出願は法人設立後に法人名義で。

## 4. S8 E&O・サイバー保険（優先順位6位）

- **候補**: ①**東京海上日動「IT業務用サイバー保険」**（IT業務の過誤＋情報漏えい＋サイバー攻撃を一本で包括） ②AIG損保「IT事業者向け業務過誤賠償責任保険」 ③**商工会議所の会員向けビジネス総合保険**（団体割引で1〜3割安くなることが多い。どのみち様式4で商工会議所に行くので入会とセットで見積もる）。
- **実勢価格**: 売上規模が小さい事業者なら年5〜15万円圏。正確な保険料は売上高申告で決まるため見積もり必須。
- **手順**: ①10月の商工会議所訪問（既存タスク4.6）の際に会員保険の資料をもらう → ②東京海上・AIGの代理店に相見積もり → ③補償額1億円・情報漏えい対応費用特約つきで比較 → 契約。
- **営業転用**: 契約後、LPと提案書に「情報漏えい賠償保険加入済み」を明記。

## 5. S6 顧問税理士＋スポット弁護士（優先順位7位）

- **税理士**: マイクロ法人の相場は**月1〜2.5万円＋決算料10〜15万円（年20〜45万円）**。freee前提なら「freee認定アドバイザー」から選ぶと記帳代行費が年12〜36万円浮く。探し方は**freee税理士コーディネーター（無料紹介）**が最短——つばめ創業セミナー受講者なのでfreeeエコシステム内で完結する。
- **弁護士（スポット）**: 契約書リーガルチェックの相場は**定型的な業務委託契約書で1通3〜5万円、複雑なもの（成果報酬型・レベニューシェア）で10〜15万円**。顧問契約は不要、必要時スポットでよい。探し方: ベンナビ・弁護士ドットコムで「IT・業務委託契約」分野を指定。
- **手順**: ①法人設立と同時にfreee税理士コーディネーターに申込（無料・オンライン面談） → ②月額2万円以下・freee対応・医療業界知見の3条件で選定 → ③弁護士は「導入150万円契約書」の初回締結前にスポット依頼（3〜5万円）。C1成果報酬型をやる時は10〜15万円の複雑契約レビューを覚悟。
- **今できる準備**: Claude Codeで業務委託契約書のドラフトを作っておき、弁護士には「ゼロから作成」でなく「レビュー」で依頼すると費用が半分になる。

## 6. A8 医療事務経験者の業務委託（優先順位12位）

- **実勢価格**: オンライン事務代行の時間単価は**2,000円前後**。クラウドワークスには医療事務資格保有者が1万人以上登録。エージェント型（クラウドワークス エージェント）なら月10万円程度から最短4営業日で稼働開始。
- **推奨形態**: 週2日×4h＝月32h×2,000円＝**月6.4万円（半年で約40万円）**。雇用でなく業務委託。
- **手順**: ①Claude Codeで業務マニュアル（検品手順・納品チェックリスト）を作成 → ②クラウドワークスで「医療事務経験・在宅・週2」で募集（トライアル1ヶ月条件付き） → ③NDA締結（上記弁護士レビュー済み雛形を使用） → ④検品・納品事務から移管開始。
- **発動タイミング**: 2027Q1（商談が月5件を超えて本人時間が枯渇し始めたら前倒し可）。

## 7. A2 医療系展示会出展（優先順位14位）

- **対象**: RX Japan「メディカルジャパン／クリニックEXPO」（クリニック院長・事務長向けの専門展）。東京（幕張）と大阪（インテックス、**2027年は9/29〜10/1**）の年2回。
- **費用**: 出展料は資料請求ベース（公式に非公開）。相場は1小間（9㎡）40〜60万円＋装飾10〜30万円。**持続化補助金の対象経費にできるので、採択後に申し込むのが鉄則**。
- **手順**: ①今すぐ公式サイトから出展資料を請求（無料） → ②補助金の事業計画に「展示会出展費」を計上（11〜12月申請） → ③採択通知後に小間を契約 → ④Claude Codeでブース配布物・デモ動画を内製し装飾費を圧縮。
- **今できる準備**: 資料請求（5分）と、来場者として2026年秋の東京展を偵察（無料・招待券）→ 出展各社のブース設計を観察。

## 8. A4 エバーグリーンウェビナー配信ツール（優先順位11位）

- **候補**: ①**MyASP（マイスピー）**: 月3,300円〜のプランあり、ステップメール＋疑似LIVEウェビナーを一本化できる国産定番 ②ウェビナー・マスター・システム（疑似LIVE特化） ③EverWebinar（海外製・日本語UI非対応なので非推奨）。
- **推奨構成**: 既にLINE公式＋自動化基盤があるので、大掛かりなツールより「**Vimeo限定公開（月2,000円台）＋LINEステップ配信で視聴URL送付＋予約はGoogleフォーム**」の最小構成から始める手もある。ツール費を月5,000円以下に抑え、広告費に予算を回す。
- **手順**: ①Claude Codeで台本・スライド生成 → ②1回だけ本気で収録（半日） → ③Vimeoにアップ、LINE配信シナリオに組込み → ④X/note/レターのCTAを「毎週水曜のオンライン説明会」に統一。
- **予算再配分**: 想定70万円のうちツール実費は年5〜10万円で済むため、残り60万円は視聴者集めの広告・レター増刷に回す。

## 9. S5 共催セミナー＋B4 ランチョンスポンサー（優先順位9・10位）

- **商工会議所ルート（S5）**: ①商工会議所に入会（年会費1〜2万円台・様式4相談と同時に） → ②経営支援・会員サービス部門に「会員向けDXセミナー」企画書を持込み → ③会場・集客は商工会議所、講師は無償〜薄謝で引き受け、終了後の個別相談枠で診断5万円につなげる。費用はほぼ交通費と資料のみで、想定40万円から大幅圧縮可能。
- **医師会・研究会ルート（B4）**: ①所属医局・知人経由で地区医師会や院長スタディグループの事務局に接触 → ②「昼の勉強会に弁当協賛＋15分講演」を提案（弁当2,000円×20人＝4〜5万円/回＋資料） → ③講演テーマは売り込みでなく「クリニックの事務コスト削減の実例」。1回15万円の想定は弁当＋会場＋資料で十分収まる。
- **今できる準備**: Claude Codeで企画書1枚と登壇スライドの雛形を先に作っておく。
