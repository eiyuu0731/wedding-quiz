# A4 エバーグリーンウェビナー台本＋LINE配信シーケンス

構成: 45分収録（Vimeo限定公開）＋LINEステップ配信で誘導。CTAは全チャネル「毎週水曜20時のオンライン説明会」に統一。

## ウェビナー台本（45分・スライド番号つき）

**タイトル: 「スタッフを増やさず、事務を月40時間減らす——クリニックAI導入の実例解説」**

| 分 | スライド | 話すこと |
|---|---|---|
| 0–3 | 1–2 | 自己紹介: 現役医師・介護と本業の傍らで自動化。「今日は売り込みの前に、実例の数字だけ持ち帰ってください」 |
| 3–10 | 3–6 | 問題提起: 事務コストの構造。求人難・時給上昇・院長の隠れ残業。「人を増やす」以外の選択肢が語られない |
| 10–25 | 7–14 | 実例3連発（事例集テンプレの数字を使用）: ①文書下書きAI化 ②問い合わせ自動応答 ③SNS自動運用。各実例は Before数字→やったこと→After数字 の順で3分ずつ |
| 25–33 | 15–18 | よくある失敗: ツールを先に買う／スタッフに丸投げ／患者情報をAIに入れる。「順番が逆です。業務の棚卸しが先」 |
| 33–40 | 19–21 | 解決の型: 診断（棚卸し・試算書）→導入→定着の3段階。診断だけで完結してよい設計の説明 |
| 40–45 | 22–24 | CTA: 「視聴者限定・今週中の診断申込は事前ヒアリングシートの詳細版つき」→ LPリンク。質疑はLINEで受付 |

収録メモ: 冒頭3分と CTA部分だけ差し替え可能な構成で撮る（料金改定時に全編再収録しないため）。

## LINEステップ配信（登録後7日間）

| Day | 配信 | 文面骨子 |
|---|---|---|
| 0 | 登録直後 | 視聴URL＋「45分あります。まず10〜25分の実例パートだけでもどうぞ」 |
| 1 | 翌日20時 | 実例①の深掘り1枚画像＋「貴院の数字で試算したい方は診断へ」 |
| 3 | 20時 | よくある質問3つ（患者情報・スタッフのITスキル・費用）への回答 |
| 5 | 20時 | 事例院長の声＋診断の空き枠案内（「今月は残り［n］枠」は実数のみ使用） |
| 7 | 20時 | 最終案内: 診断5万円の内容再掲＋「合わなければ診断で終了、それも歓迎」 |

運用メモ: 誇大表現・架空の限定性は使わない（信頼が商品）。開封・遷移の計測は既存のKPIスコアボードに週次で記録。
