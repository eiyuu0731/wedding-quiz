# A8 医療事務スタッフ（業務委託）——業務マニュアル＋募集文面

## 1. クラウドワークス募集文面

**タイトル**: 【在宅・週2日】医療事務経験者募集｜クリニック向け資料の検品・発送管理（医療機関との折衝なし）

**本文**:
現役医師が代表を務めるクリニック向けAI導入支援会社です。事業拡大に伴い、医療事務のご経験を活かして在宅で支えてくださる方を募集します。

- 業務: ①AIが生成したクリニック向け資料の検品（誤字・医療用語の誤用・失礼表現のチェック） ②DM発送の入稿管理（ラクスル操作、手順書あり） ③納品物の送付状作成・進行管理
- 条件: 週2日×1日4時間目安／完全在宅／時間単価2,000円（試用1ヶ月は1,800円）
- 必須: 医療事務またはクリニック勤務経験2年以上／基本的なPC操作
- 歓迎: レセプト業務経験、文章チェックが得意な方
- 契約: 業務委託（NDA締結必須）。患者情報・診療情報は一切扱いません
- 選考: 書類 → 検品テスト（30分・サンプル資料の誤り探し）→ オンライン面談15分

**検品テストの作り方**: 実物レターにわざと誤り8個（用語誤用3・敬語2・数字2・体裁1）を仕込み、発見数6以上で合格。

## 2. 業務マニュアル（検品・発送・納品）

### 検品チェックリスト（レター・納品資料 共通）
1. **医療用語**: 診療科名・検査名・薬機法に触れる表現（「治る」「必ず」等の断定）がないか
2. **数字**: 削減時間・金額が試算書と一致しているか。単位（時間/月・円/年）の混在がないか
3. **宛名**: 医院名・院長名の誤字は一発アウト項目。CSVと突合
4. **敬語・失礼表現**: 上から目線の助言表現（「〜すべき」→「〜の余地があります」）
5. **体裁**: 1枚に収まっているか、QR/URLが生きているか（実際に踏む）
6. 判定: 修正が3ヶ所以下→自分で直して発送可。4ヶ所以上→差し戻し（Slack/LINEで報告）

### DM発送手順（ラクスル）
1. 共有フォルダの「発送待ち」からPDFとCSVを取得
2. ラクスルにログイン → DM印刷 → 前回と同仕様（A4封書・モノクロ/カラーは指示に従う）
3. 校正プレビューで検品チェックリスト1〜5を再実施
4. 発注 → 発注番号を進行管理シートに記録 → 「発送済み」フォルダへ移動

### 週次報告（毎金曜・定型3行）
「今週の検品◯件（差し戻し◯件）／発送◯通／気づき1行」

### 禁止事項
- 患者情報・診療情報の受領（送られてきたら開かずに報告）
- 資料の二次利用・外部共有（NDA第◯条）
- 医療機関への直接連絡（窓口は代表のみ）

## 3. 立ち上げ手順（本人側）
1. 検品テストを作成（30分）→ 2. 募集掲載 → 3. 応募から3名に検品テスト → 4. 合格者と面談・NDA（契約書ドラフトの雛形使用）→ 5. 試用1ヶ月は全件ダブルチェック → 6. 差し戻し率10%未満で単独検品に移行
